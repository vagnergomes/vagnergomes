### 🏛️ Sobre Mim

Atuo há mais de 7 anos no desenvolvimento de soluções tecnológicas end-to-end, conectando o chão de fábrica ao ecossistema corporativo. Minha atuação abrange desde o controle e programação de hardware e periféricos industriais até a arquitetura de microsserviços, dashboards supervisórios e plataformas web de alta disponibilidade.

* **Automação & Chão de Fábrica:** Programação de CLPs, desenvolvimento de interfaces IHMs/SCADA, integração de balanças, leitores RFID/NFC, sistemas de visão computacional e controle de acesso físico.
* **Sistemas & Integrações:** Construção de APIs REST, comunicação em tempo real via WebSockets, mensageria via Webhooks e pipelines de dados ETL conectando bancos relacionais e plataformas ERP/Sênior/SAP.
* **Aplicações de Missão Crítica:** Desenvolvimento de PWA offline-first para operação em campo, microsserviços containerizados e serviços de segundo plano para ambiente Windows/Linux.
